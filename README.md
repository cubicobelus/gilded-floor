# Gilded Floor

### [▶ Play it now](https://cubicobelus.github.io/gilded-floor/gilded_floor.html)

A first-person casino tycoon in your browser. You walk the floor yourself: place machines as ghosted previews in front of you, sit down and play your own games, watch guests arrive from the car park, and run the business from a set of side panels. Plain HTML, CSS and JavaScript in a single file, no build step.

## Play

Use the link at the top: nothing to download or install. It is built for a desktop browser with a keyboard and mouse (it uses mouse look), so it is not meant for phones.

To run it offline, download `gilded_floor.html` (open the file on GitHub and click "Download raw file", or use Code > Download ZIP) and open it in any modern browser. It is one self-contained file and needs no internet connection.

Click the page to start. You begin with $5,000 and a closed, empty casino: buy a first machine from the Build tab, then open the doors.

## Features

- **A real gambling floor:** nine table games and seven slot families. Baccarat follows real Punto Banco drawing rules, the roulette ball lands in the pocket that actually won, and the Big Wheel stops on the segment it reports
- **Play it yourself:** sit at any machine and play your own cash, or let guests fill the seats
- **Rigging, and the risk:** tilt a machine's payout, and an inspector may catch you (rigging can never help you when you play)
- **Guests with minds of their own:** wallets, hunger, thirst, personalities, regulars who remember how you treated them, and the occasional cheater
- **Staff:** seven roles with names, XP, morale and pay rates you set
- **Hotel, dining and bar:** front desk, three room tiers, a kitchen with chefs, bars, restrooms, a cashier's cage and more
- **Build freely:** expand the floor, add an upper floor with stairs and a lift, wallpaper, decor and interior walls
- **Run it like a business:** daily reports, department profit and loss, loans, a Player's Club, marketing, random events, a star rating and achievements
- **Quality of life:** minimap, photo mode, rebindable keys, save export and import, and the casino clock pauses while the doors are closed

## Controls

All keys can be rebound in Settings.

| Action | Default |
|---|---|
| Move / run / jump | `W A S D` / `Shift` / `Space` |
| Interact | `F` |
| Rotate item | `R` / `E` |
| Grab and move an item | `G` |
| Cancel / back out | `Q` |
| Repeat last placement | `C` |
| Minimap / switch map floor | `M` / `N` |
| Photo mode | `P` |
| Side tabs | `1` to `8` |
| Switch Look Mode and UI Mode | `Tab` |

## Privacy

Everything runs in your browser. The game saves to your browser's local storage (or to a file you export) and nothing is sent anywhere. It makes no outside requests at all: the 3D library is included in the file.
